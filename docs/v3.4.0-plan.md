# v3.4.0 开发方案：画廊悬停预览

状态：实现与本机可执行验收完成（2026-10-23），待发布。基线 v3.3.1；本计划是当前唯一活动版本计划。

## 范围与默认行为

- E-Hentai / ExHentai 关闭卷轴时，在原生画廊内部网格提供鼠标悬停预览。
- 通用预览器负责交互和展示；站点适配器只把原生元素映射到已识别 GalleryItem 的稳定 key。
- 设置为关闭、适应窗口、紧凑三选一，默认适应窗口；持久化设置，仅有接入能力且关闭卷轴时显示。
- 稳定悬停 400 ms 才获取清晰图；先显示已有 URL / Sprite 缩略图，没有廉价预览则显示加载反馈。
- 适应窗口等比完整显示，约束在窗口宽高的 90%；紧凑预览靠近目标、自动换边并限制在窗口内。
- 浮层不接收指针、不抢焦点、不改变原生点击行为。移出、滚动、按键、指针按下、窗口失焦、
  页面隐藏、窗口尺寸变化或 Reader 打开时关闭；关闭后须移出再移入才重新触发。
- 纯触摸不启用；混合设备允许鼠标。预览不提供翻页、拖拽、滚轮缩放、固定浮窗或任意图片扫描。

## 架构与资源边界

1. 在 SiteAdapter 增加一个小型可选目标识别能力；E-Hentai 的选择器和链接规则只留在 sites/。
   通用层只处理已存在于 GalleryItem 集合的 key，不为未知链接启动请求。
2. 新增独立的 preview/ 模块，不启动 ReaderSession 或 PhotoSwipe，不依赖具体站点或 UI Store。
   app/ 负责依赖组装、设置和 Reader 状态协调。
3. 使用现有 acquireImage / ImageLoadService；沿用站点限流、转换、缓存和有界重试。
   preview 是实时需求，但每次仅持有当前一张图的租约，不预取邻页。
4. 关闭或切换时移除展示节点后释放租约；共享任务只在没有其他消费者时取消，过期回调不得覆盖新目标。
   不创建独立下载队列、缓存、Object URL、持续 RAF、逐图片监听器或全页 MutationObserver。
5. 保留既有前三张 warmup，悬停需求通过共享优先级提升到前台；不再另设预热机制。

## 验收门槛

- npm run typecheck、npm test、npm run build、git diff --check 全部通过。
- Chrome DevTools 实际浏览器验证：真实 E-Hentai 画廊的目标识别、图片解析和清晰图显示；
  ExHentai 如访问受限则明确记录限制，不能把 fixture 当作真实站点通过。
- URL 与 Sprite 缩略图、横图 / 竖图、窗口边缘、两种尺寸、设置持久化、关闭开关均验证。
- 400 ms 内快速扫图不产生预览请求；目标切换 / 移出可取消无主任务，迟到图不覆盖当前图；
  反复开关只保留一个浮层，关闭后零预览租约、零预览 timer、零预览 phase 监听器。
- 同图预览再次显示及 Reader 使用应复用服务结果；预览不能改写 Reader 页码 / 导航 / 返回位置。
- 浏览器验证滚动、Escape、点击链接、Reader 开关、页面隐藏与 resize 关闭；触摸事件不触发，
  混合输入能力和纯触摸条件有自动化覆盖。移动手势逻辑不修改，不以桌面模拟代替真机手势验收。
- 性能记录条件与关键数字：快速扫图请求数、重复悬停请求数、浮层 / 租约数量、压力前后内存趋势。
  网络故障和取消不能无限重试；不得新增站点名称分支、依赖库或独立网络 / 缓存实现。

发布由用户另行决定；本轮完成实现和验收后保留这份方案，记录结果与实际限制。

- Reader 手势精简：删除自定义 DOM mouse 点击补偿，Spread 图片、占位与中缝由 Driver

  保留原生缩放按钮、Z 键、双指缩放与拖曳手势。不得另加手势状态机或关闭兜底 timer。
  验收须通过真实 CDP 鼠标上下拖曳（含松开后浏览器 click）、触摸模拟、单页 / 双页 / pending

  相同浏览器样本已在原 HEAD 控制器复现，验收增加当前 holder / 逻辑页 / 实际来源一致性。
- 验收：章节元数据回归、实际 Driver 的快速关闭 / 重开 / 初始化失败浏览器回归、真实章节解析检查，

GM 存储用测试标签页 sessionStorage 替身，并在构建脚本的副本中暴露 Store / 服务以读取诊断计数。
这些诊断没有写入生产源码。隔离浏览器上下文中移除广告 iframe，避免第三方动画污染压力结果。

  竖图样本 1280×1972 在 1252×1270 窗口显示约 742×1143；横图按宽度约束完整显示，截图人工核对。
- 原生 Sprite 占位实际验证；URL 占位通过真实 DOM 中替换标准 descriptor 的受控测试验证。
  不把该受控 URL 样本声称为站点原生 URL 缩略图模式验收。
- 鼠标真实 hover、Escape、设置按钮切换通过；设置写入存储后重新加载并再次初始化，compact 保持。
  点击原生缩略图仍进入正确 `/s/` 页面；浮层 pointer-events 为 none，不改变点击和焦点。
- 浏览器 60 次快速扫图（每项约 20 ms）新增解析 / 共享字节任务均为 0。

- 滚动、visibilitychange、blur、resize、pointerdown、pagehide 的关闭路径通过浏览器事件测试；
  未知 key 与 touch 指针均不启动预览。纯触摸 375×829 设备模拟下两类精细悬停查询均为 false，
  即使注入 mouse 事件也没有浮层。混合指针由自动化覆盖，本轮未修改 Reader 的移动手势实现。
- 640×800 浏览器窗口：fit 为 576×329、compact 为 520×297，均在窗口内；右侧目标自动换至左侧。
  自动化另覆盖 375×829 和 1280×300 的布局边界。
- 卷轴启用的真实页面检查：无预览浮层、无预览设置项，Reader 正常开关且返回位置保持。

### 性能与资源

在 640×800、已完成前三张 warmup 的风景画廊，重复同图悬停约 430 ms 后关闭，共 100 次：

| 项目 | 结果 |
| --- | --- |
| 新增共享解析 / 字节加载调用 | 0 / 0 |
| 关闭后的页面元素总数 | 始终 332 |
| 关闭后的预览浮层 / 活动租约 / phase 监听 | 0 / 0 / 0 |
| 第二组 50 次的 >50 ms 长任务 | 0 |
| 两组之间与完成后的 GC 堆快照 self size | 4,062,088 → 4,068,829 bytes |
| 快照 detached 节点数 | 43 → 43 |

首次与缓存重新挂载的 `<img>` 仍可能出现在 DevTools Network 列表；缓存样本耗时约 0–0.7 ms，
源响应允许一年缓存。跨域 Resource Timing 未公开传输体积，因此这里不把“无新增服务任务”
等同于“浏览器层永远无任何请求记录”。后续如发现缓存重新挂载产生实质重复传输或持续内存增长，
应按真实网络 / 堆证据重新评审；本次没有增加 Blob 下载缓存或独立资源池。
